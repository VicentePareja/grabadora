# Grabadora

Graba tu pantalla con tu cara (cámara) en una burbuja encima. Todo corre en el navegador: nada se sube a ningún servidor.

**Úsala aquí:** https://vicentepareja.github.io/grabadora/

## Cómo se usa

1. Abre la página en Chrome o Edge y acepta el permiso de cámara y micrófono.
2. Pulsa **Elegir pantalla** y escoge la pantalla, ventana o pestaña.
3. Arrastra la burbuja de la cámara donde quieras y ajusta su tamaño.
4. Pulsa **Grabar**. Puedes minimizar la ventana mientras grabas.
5. Pulsa **Detener** (o "Dejar de compartir"). El video se descarga solo.

Opcional: marca **Guardar también cámara y pantalla por separado** para recibir además un archivo solo de pantalla y otro solo de cámara (útil para editar).

El video sale en MP4 (H.264 + AAC) si el navegador lo soporta; si no, en WebM.
